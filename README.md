# 🧮 Calculator Web App

A simple and responsive Calculator built using **HTML**, **CSS**, and **JavaScript**. This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Live Demo

🌐 Live Website: https://elamu006.github.io/calculator/

## 📌 Features

* Addition (+)
* Subtraction (-)
* Multiplication (×)
* Division (÷)
* Clear Screen Function
* Delete/Backspace Function
* Responsive Design
* Mobile Friendly UI
* Fast and Lightweight

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 📂 Project Structure

```text
calculator/

```

## 💻 Installation

1. Clone the repository

```bash
git clone https://github.com/elamu006/calculator.git
```

2. Open the project folder

```bash
cd calculator
```

3. Run the project

Open `index.html` in your browser.

## 🎯 How It Works

* User clicks calculator buttons.
* JavaScript captures button inputs.
* Mathematical expressions are displayed on the screen.
* The result is calculated and shown instantly.

## 📱 Responsive Design

The calculator is fully responsive and works smoothly on:

* Mobile Phones
* Tablets
* Laptops
* Desktop Computers
